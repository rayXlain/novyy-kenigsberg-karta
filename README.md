# Новый Кёнигсберг — карта проектов

Интерактивная карта концепции развития Калининграда: 17 проектов с оценкой
стоимости, приоритетами, сценариями и нерешёнными развилками.
**Ничего из показанного не построено — это гипотезы.**

Страница собирается из заметок Obsidian-хранилища генератором `build.py`.
Геометрия линий и объектов — реальная (OSM, OSRM); контуры районов схематичны.
